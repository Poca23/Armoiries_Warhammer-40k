# Armoiries Warhammer 40k - Les Grenadiers d'Asgard

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 📋 Description

Portfolio web présentant la création d'armoiries héraldiques personnalisées pour l'armée Warhammer 40k **"Les Grenadiers d'Asgard"**. Le projet documente l'intégralité du processus créatif, des recherches initiales aux maquettes finales en couleur.

## 🎯 Objectif

Concevoir des armoiries médiévales-futuristes pour des figurines Warhammer 40k, inspirées des Grenadiers de Napoléon, intégrant :

- Un **Gryph-charger** comme animal héraldique
- Charte colorimétrique : Bleu / Blanc / Rouge / Noir
- Formats adaptés aux drapeaux d'armée (max 400×350mm)
- Symboles de loyauté et de puissance

## 🛠️ Technologies utilisées

### Frontend

- **HTML5** - Structure sémantique
- **CSS3** - Design moderne et responsive
  - CSS Variables (Custom Properties)
  - CSS Grid & Flexbox
  - Animations & Keyframes
  - Media Queries
- **JavaScript (Vanilla)** - Fonctionnalités dynamiques
  - Session Storage API
  - Event Listeners
  - Scroll Management

### Outils graphiques

- **Photoshop / Illustrator** - Création des armoiries
- **Formats** : PNG, JPG

## ✨ Fonctionnalités

- ✅ Design **responsive** (mobile-first)
- ✅ Galeries d'images **adaptatives**
- ✅ Navigation fluide avec **boutons scroll-to-top**
- ✅ **Sauvegarde automatique** de la position de scroll
- ✅ Animations CSS **fluides**
- ✅ Mode **impression optimisé**
- ✅ **Accessibilité** (liens externes sécurisés)

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/votre-username/armoiries-warhammer.git

# Accéder au dossier
cd ARMOIRIES_WARHAMMER

# Ouvrir avec un serveur local (recommandé)
# Ou double-cliquer sur index.html
````

### Serveur local (optionnel)

```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js (http-server)
npx http-server
```

## 💻 Utilisation

1. Ouvrez `index.html` dans votre navigateur
2. Parcourez les différentes sections :
   - **Pitch** : Introduction du projet
   - **Étapes** : Processus créatif détaillé
   - **Maquettes finales** : Résultats en haute résolution
3. Utilisez les boutons de navigation pour revenir en haut
4. La position de scroll est sauvegardée automatiquement
